# Sourcebook 7 PWA port

The first standalone build ports the Sourcebook 5 shell, query and view behavior, and local catalog workflows. Folder handles are remembered in IndexedDB. The selected folder holds the catalog, per-file metadata, workspace, durable operation receipts, originals, and separate flat thumbnail and preview directories. Format 1 uses the original UTC timestamp and per-second counter as the file stem. The static build precaches its runtime, including PDF workers and support files.

Verified the production build. The Chrome smoke pass used a disposable browser filesystem directory through the same handle interface as the native picker. With the browser network disabled, the app reopened, browsed and switched libraries, added a file, rendered Markdown and PDF, edited metadata and Markdown, adopted an external addition, recognized an external move by ID, processed a share-target POST, and downloaded PNG bytes under the original name. Desktop and narrow layouts were checked. A focused Node check verified 100 consecutive IDs, persistence through a new allocator instance, and byte comparison.

Native Windows folder selection and Windows file launch still need a manual pass. Android folder access and OS share intake still need a physical Android test. The browser test validated the PWA share handler without the Android share sheet.
