# Recover failed Windows shortcut captures

Retry converts a browser-retained `.url` draft into a plain-text `.link` file when it contains a valid HTTP or HTTPS address. An unfinished upload receipt with no published destination retains its library ID, resource ID and folder. The app keeps invalid shortcuts in Needs attention.

A focused check replayed the failed receipt state seen in the local test library. It verified the converted bytes, preserved ID, idempotent retry and occupied-destination handling. The production build passed.
